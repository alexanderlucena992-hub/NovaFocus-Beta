## NovaFocus


Hello everyone, this is my first project called NovaFocus, which has a language selector with both Spanish and English options and a notification search function (limit 3_).

## How can I open the project?

* In your terminal, run ./focus
* The program will open in your Linux terminal; select the language and block notifications.

```
cd "/home/user/Descargas/NovaFocus"
./focus
Selecciona idioma / Select language:
1. Español
2. English
> 
```

## What does this program consist of?

* This program blocks notifications for developers who are programming and don't want to be distracted.
